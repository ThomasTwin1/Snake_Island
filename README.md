# 🐍 Snake Island

A text-based Python adventure game built while learning Python fundamentals.

## Overview

Snake Island is an interactive terminal game where the player makes decisions that determine the outcome of the adventure. The project focuses on building programming fundamentals while demonstrating problem solving and program flow.

## Features

- Interactive command-line gameplay
- Branching story paths
- User input handling
- Conditional logic
- Multiple game outcomes

## Technologies

- Python 3

## Skills Demonstrated

- Variables
- Functions
- Conditional statements
- User input
- Program flow
- Debugging

## Lessons Learned

This project strengthened my understanding of Python fundamentals and taught me how to organize code into a complete interactive application.
